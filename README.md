# SwitchWise UK

A free static UK household-bills calculator and guide site. It uses no backend, paid API, login or database.

## Live URL
https://skar-the-dev.github.io/switchwise-uk/

## Tools
- Monthly bill comparison calculator
- Annual gas and electricity estimator with separate standing charges
- Broadband contract cost calculator
- Mobile contract cost calculator
- Monthly savings goal planner
- Dedicated energy, broadband and mobile guide/calculator pages

## Hosting
The project is designed for GitHub Pages on the `main` branch from the repository root. No paid hosting or custom domain is required.

## Search visibility
- Descriptive page titles and meta descriptions
- Canonical URLs and Open Graph metadata
- XML sitemap and robots.txt
- Internal links between the home page and focused guides

After the site is live, add the exact GitHub Pages URL as a property in Google Search Console and submit `https://skar-the-dev.github.io/switchwise-uk/sitemap.xml`. Search Console is free. Indexing and ranking are not guaranteed.

## Monetisation status
There are no active affiliate links or paid partner placements yet. Awin states that publisher sign-up is free, but publisher and individual advertiser approval are required. Do not add tracking links until a programme has approved the site and its terms have been checked.

## Before monetisation
- Confirm the site operator identity and public contact details.
- Review privacy, cookie/consent, advertising and consumer-information obligations for the features actually enabled.
- Apply to suitable partners and wait for approval.
- Label each advertising link clearly beside the relevant content.
- Use approved, working tracking links only.
- Keep all claims, provider details and prices current and verifiable.

## Revenue reality
This is a free-to-start foundation, not guaranteed income. Search traffic takes time to build, partner programmes can reject applications, and earnings depend on qualified visitor actions. The site currently calculates using visitor-entered figures; it does not show live tariff or deal data.

## Local checks
Check that every HTML page loads, all forms validate, result calculations match the formulas, and the XML sitemap URLs match the deployed Pages URL.
