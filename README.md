# SwitchWise UK

Free static UK household-bills calculator toolkit. No backend, paid API, login or database required.

## Included
- Bill savings calculator
- Energy cost estimator
- Broadband contract cost calculator
- Monthly savings goal calculator
- Privacy and affiliate-disclosure starter pages
- Responsive mobile layout

## Publish free with GitHub Pages
1. Open repository Settings → Pages.
2. Choose Deploy from a branch, select main and / (root), then Save.
3. Wait for the Pages URL to appear.

## Before public launch
- Add a real operator/contact method to the footer and privacy page.
- Review legal/privacy obligations for your use and jurisdiction.
- Add Search Console and a sitemap after the final URL is known.
- Apply to legitimate affiliate/comparison programmes. Approval is not guaranteed.
- Only add approved tracking URLs. Do not invent prices, rankings, savings claims or live offers.
- Clearly label affiliate links.
- Add analytics/cookies only with appropriate notices and consent controls where required.

## Revenue reality
This is a free-to-start foundation, not guaranteed income. Traffic takes time; affiliate programmes may reject applications and monetisation may require eligibility thresholds. Calculator estimates are not live quotes.
